# rifttoken

Rift host/token network string helpers for config audits.

**Site:** https://theworker02.github.io/rifttoken/

## Install / run

```bash
git clone https://github.com/theworker02/rifttoken.git
cd rifttoken
node src/cli.js
node --test
```
